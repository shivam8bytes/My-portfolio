# Shivam Singh — Portfolio

A responsive, futuristic personal portfolio built with **HTML, CSS and vanilla JavaScript**.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser. For best results, use VS Code with the Live Server extension.

## Personalise before publishing
Open `script.js` and update:
- `GITHUB_USERNAME` — your GitHub username (enables the live public repository feed).
- `CONTACT_EMAIL` — your professional email address.
- `LINKEDIN_URL` — your LinkedIn profile URL.

Update the project cards in `index.html` with real project descriptions, GitHub links and live demos as your work is ready. The current cards are starter content, not claims of completed projects.

## Résumé
The Download résumé button links to `assets/Shivam_Singh_Resume.pdf`. Update the PDF with your university name, contact details, current projects, certifications and dates before using it for applications.

## Publish
You can host this static site using GitHub Pages:
1. Create a GitHub repository.
2. Upload the contents of this folder (not the ZIP itself).
3. In repository Settings → Pages, choose the main branch and root folder.
4. Save and wait for GitHub Pages to publish the site.

## Notes
- The profile photo is the photo supplied for this portfolio.
- Google Fonts are loaded online; the rest of the site is static.
- The GitHub widget uses the public GitHub REST API and requires an internet connection.
